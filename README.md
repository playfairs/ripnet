# [ripnet](https://ripnet.cc)

![](./assets/icon/ripnet-banner-(500x100).png)

Network diagnostics, packet analysis, observability, and authorized load-testing toolkit.

---

## Requirements

- Linux, macOS, or BSD
- gcc
- libpcap
- make

## Installation

```bash
make
sudo make install
```

## Usage

```bash
ripnet --help
```
