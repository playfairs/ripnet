# ripnet ![](https://rv.playfairs.cc/ripnetwork/ripnet)

![](./assets/ripnet-text.png)

Network diagnostics, packet analysis, observability, and authorized load-testing toolkit.

---

## Requirements

- Linux, macOS, or BSD
- gcc
- libpcap
- make

## Installation

```bash
make
sudo make install
```

## Usage

```bash
ripnet --help
```
